TEA国際集会の講習会（2時間・ハンズオン形式・日本語で実施）で使う資料の配布ページです。このページだけブックマークしてください。

1. ツールを開く

インストールもアカウント登録も不要です。Chrome または Edge で下のボタンから開いてください。

TEMerPlus を開く GitHub リポジトリ

うまく開けないときは、ページを再読み込みするか、別のブラウザ（Chrome / Edge）でお試しください。Internet Explorer には対応していません。

毎回アドレスを開くのが面倒な場合は、ブラウザの「アプリとしてインストール」「ショートカットを作成（ウィンドウとして開く）」を使うと、独立したウィンドウから起動できます（名称はブラウザと版で異なります）。中身は同じものなので、ネット接続は必要です。図のデータは手元のブラウザの中だけで処理され、サーバーへ送信されません。

2. 練習用ファイルをダウンロード

ハンズオンで使うサンプルです。まとめてダウンロードしておくと当日スムーズです。解凍すると temerplus_tea2026 フォルダに展開されます。

練習用ファイル一式（ZIP）

個別に取得する場合は下記からどうぞ。当日必ず使うのは最初の2つです。

demo_boxes.csv 切片の表から Box を作る（当日使用）
demo_lines.csv Box どうしをつなぐ矢印（当日使用）
demo_sdsg.csv SD・SG を一括で追加
demo_periods.csv 時期区分のラベル
demo_boxes_1col_切片のみ.csv ラベル列だけの最小構成
demo_boxes_2col_切片＋Time.csv 横位置（時間）を指定
demo_boxes_3col_切片＋Time＋Item.csv 横位置と縦位置を指定
協力者A_第1回.txt ほか3件 逐語録の取り込みサンプル（txt / csv / docx / xlsx）。持ち帰って試す用

取り込みの順序は Box → Line → SD/SG → 時期 です。Line と SD/SG は Box の ID を参照するため、Box を先に入れてください。各ファイルの詳しい説明は ZIP 同梱の README_サンプルの説明.md にあります。

4. 当日の流れ

10分TEM図の作図と報告、いま何が問題か
8分起動と画面の見方
35分ハンズオン A：はじめての TEM 図を作る
7分部品の整理（Box・Line・SD/SG・凡例）
5分休憩
20分ハンズオン B：手元の表から図を起こす
15分ハンズオン C：論文用レポートを書き出す
20分まとめ・質疑

5. 事前のご準備

  • ノート PC（Chrome または Edge）。タブレット・スマートフォンでの操作には向きません。
  • インストール・アカウント登録・事前のデータ準備は不要です。
  • 上記2の練習用ファイルをダウンロードしておいてください（当日その場でも配布します）。
  • ご自身の研究データをお持ちいただく必要はありません。お持ちの場合、切片が表になっていればハンズオン B でそのまま使えます。

6. 困ったとき

  • 操作を取り消したい：Ctrl + Z（やり直しは Ctrl + Y）。
  • 保存し忘れて閉じた：次回起動時に「復元しますか？」と聞かれます。
  • 機能が見つからない：Ctrl + K でキーワード検索ができます。
  • 動作がおかしい：ページを再読み込みしてください（保存済みなら .tem ファイルを開き直せます）。
