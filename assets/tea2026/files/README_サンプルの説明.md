# TEMerPlus 取り込みデモ用ファイル

チュートリアル講座の「取り込みデモ」で使うサンプル一式．実装側パーサ
（`webApp/src/utils/transcriptImport/`, `csvImport.ts`）の期待構造に合わせて
あり，**自動マッピング・話者検出がそのまま通る**ことを実機で確認済み．

題材は講座のハンズオンと同じ「**研究テーマ決めの経緯**」に揃えてある．

再生成は `uv run generate.py`．

---

## 2 つの「読み取り方式」

TEMerPlus の取り込みは入口が 2 系統ある．デモもこの 2 つに分かれる．

### A. 原文（インタビュー逐語録）インポート ― 4 形式
**入口**：ファイル → **原文**（単体）／**原文一括**（複数）／起動ウィザード「ファイルから新規作成」
対応形式：`.txt` / `.md` / `.csv` / `.tsv` / `.xlsx` / `.xls` / `.docx`

| ファイル | 形式 | 見どころ |
|---|---|---|
| `協力者A_第1回.txt` | txt | 空行で段落区切り＋「話者：本文」．話者 `聞き手` / `A` を自動検出 |
| `協力者A_第2回.csv` | csv | ヘッダ `話者,時刻,発言` を自動マッピング（話者列・時刻列・本文列） |
| `協力者B_第1回.docx` | docx | 段落先頭の**太字話者名＋コロン**を検出 |
| `協力者B_第2回.xlsx` | xlsx | 1 シート・`話者,時刻,発言` |

- 4 ファイルとも**ファイル名から協力者・回数を自動推測**する（`協力者A_第1回` → 協力者 A・第 1 回）．
  「**原文一括**」で 4 つまとめて取り込むと、この自動推測が一覧で見せられる．
- 取り込み後は「原文ビューア」に段落が並び、各段落から **Box 追加 / 既存 Box にリンク**できる
  （逐語録 ↔ TEM 図のトレーサビリティ）．

### B. 切片 → 図要素 CSV インポート
**入口**：ファイル → **CSV インポート…**（ダイアログ上部の「インポート対象」で 4 種を切替）

| ファイル | 対象 | 列（ヘッダ） |
|---|---|---|
| `demo_boxes.csv` | Box | `ID, ラベル, 種別, Time Level, Item Level, 説明` |
| `demo_lines.csv` | Line（矢印） | `From, To, 種別, 形状, 説明` |
| `demo_sdsg.csv` | SDSG | `種別, ラベル, attachedTo, 説明` |
| `demo_periods.csv` | 時期ラベル | `位置, ラベル` |

#### 列数を増やす段階デモ（Box 取り込み・同じ切片で比較）
同じ 8 切片（興味分野→…→学会発表する自分）を，列を 1→2→3 と増やして用意．
「列が増えるほど配置が自分の意図どおりになる」流れを見せられる．

| ファイル | 列 | 取り込み結果 |
|---|---|---|
| `demo_boxes_1col_切片のみ.csv` | ラベル | 種別=通常・**左から自動で順に並ぶ**（位置指定なし） |
| `demo_boxes_2col_切片＋Time.csv` | ラベル, Time Level | **横位置（時間）を指定**して並ぶ |
| `demo_boxes_3col_切片＋Time＋Item.csv` | ラベル, Time Level, Item Level | **横＋縦位置**を指定（EFP を上・P-EFP を下） |

> いずれも種別列がないので全 Box は「通常」で入る（種別は取り込み後にプロパティで変更，
> または `demo_boxes.csv` のように種別列付きを使う）．「種別未指定時のデフォルト」も
> ダイアログで選べる．

**重要：取り込み順序**（Line / SDSG は Box の ID を参照するため）
1. `demo_boxes.csv`（B1〜B8 が作られる）
2. `demo_lines.csv`（B1→…→B6 実線 5 本、B3→B7 と B5→B8 の点線 2 本）
3. `demo_sdsg.csv`（B4 に SG「指導教員のヒント」、B3 に SD）
4. `demo_periods.csv`（Time 1=探索期、Time 4=決定期）

> Box ID（B1〜B8）は `demo_boxes.csv` の ID 列で固定している．Line / SDSG の
> `From`/`To`/`attachedTo` がこの ID を参照する．順序を逆にすると「該当 Box なし」で
> スキップされるので注意．

## デモの想定図（B 群の対応）

```
                                                    ‥→[学会発表する自分(潜在経験)] B8
                                          SG／SD
                                            △▽
[興味分野]→[文献検索]→[テーマ案(BFP)]→[研究計画の提出(OPP)]→[ゼミ発表]→[テーマ確定(EFP)]
   B1        B2          B3                  B4              B5          B6
                          └ ‥点線(XLine)‥→ [別テーマ継続(P-EFP)] B7
```

## 動作確認メモ（2026-06-22）

実機（vite dev）で以下を確認済み：
- `demo_boxes.csv` → 8 Box（Box 6 種別すべて）が時系列配置・種別どおり描画
- `demo_lines.csv` → 7 件（実線 5・点線 2）が Box 間に接続
- `協力者A_第1回.txt` → 7 段落・話者 `聞き手`/`A` を自動検出、原文ビューアに展開

> 種別語・列名はパーサの辞書に準拠（種別：通常/分岐点/等至点/両極化等至点/必須通過点/潜在経験，
> 線種：実線・点線，形状：直線/L字/曲線）．列名は日本語・英語どちらでも自動認識される．
